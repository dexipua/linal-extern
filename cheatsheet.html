Аркуш А4

Шпаргалка

На тест дозволено один односторонній аркуш А4. Сторінка верстається під друк на одному аркуші. Краще перепишіть її від руки й додайте те, у чому самі помиляєтесь.

СЛАР: скільки розв'язків

  • Рядок 0 … 0 | c, c ≠ 0 → несумісна.
  • Сумісна, r = n → єдиний; r < n → безліч, вільних n − r.
  • Дозволено: обмін рядків; рядок·k (k ≠ 0); рядок + k·інший.
  • Однорідна: завжди x = 0; нетривіальні ⇔ r < n ⇔ (квадратна) det = 0.
  • Параметр: не ділити на вираз із параметром; нулі det — «підозрілі» значення.
  • Ax = x₁a₁ + … + xₙaₙ: сумісна ⇔ b — комбінація стовпців.
  • Крамер: xⱼ = Δⱼ / Δ, Δⱼ — j-й стовпець замінено на b.

Матриці

  • (m×n)(n×p) = m×p. AB ≠ BA загалом.
  • (AB)ᵀ = BᵀAᵀ, (AB)⁻¹ = B⁻¹A⁻¹.
  • (A+B)² = A² + AB + BA + B².
  • DA — масштаб рядків, AD — стовпців.
  • AᵀA, AAᵀ — симетричні. A = (A+Aᵀ)/2 + (A−Aᵀ)/2.
  • f(A): вільний член множиться на I.
  • Підпростір: 0 ∈ W, замкнений щодо + і ·λ.
  • Залежні ⇔ ранг < кількості векторів; n векторів у ℝⁿ: ⇔ det = 0.

Визначник

  • 2×2: ad − bc.
  • Саррюс (лише 3×3): a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂ − a₁₃a₂₂a₃₁ − a₁₂a₂₁a₃₃ − a₁₁a₂₃a₃₂.
  • Розклад: Σ aᵢⱼ(−1)ⁱ⁺ʲMᵢⱼ; знаки + − + / − + − / + − +.
  • Трикутна: добуток діагоналі. Обмін рядків: −; рядок·k: ·k; рядок + k·інший: без змін.
  • det Aᵀ = det A; det(AB) = det A·det B; det(kA) = kⁿ det A; det A⁻¹ = 1/det A.
  • Нульовий / пропорційні рядки → 0. det(A+B) ≠ det A + det B.
  • |det| — коефіцієнт зміни площі; det < 0 — зміна орієнтації.

Обернена

  • a b; c d⁻¹ = 1ad−bcd -b; -c a
  • [A | I] → [I | A⁻¹]; нульовий рядок зліва → оберненої немає.
  • A⁻¹ = adj A / det A.
  • AX = B ⇒ X = A⁻¹B; XA = B ⇒ X = BA⁻¹; AXB = C ⇒ X = A⁻¹CB⁻¹.
  • Ax = b ⇒ x = A⁻¹b. Перевірка: AA⁻¹ = I.
  • Невиродженість: det ≠ 0 ⇔ ∃A⁻¹ ⇔ rank = n ⇔ стовпці незалежні ⇔ Ax = 0 лише x = 0.
