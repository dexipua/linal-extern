Знайдіть загальний розв'язок: x₁ + x₂ − x₃ + 2x₄ = 3
2x₁ + 3x₂ + x₄ = 7
x₁ + 2x₂ + x₃ − x₄ = 4
Відповідь
Зведена форма: 1 0 -3 5 ¦ 2; 0 1 2 -3 ¦ 1; 0 0 0 0 ¦ 0.
x₁ = 2 + 3s − 5t, x₂ = 1 − 2s + 3t, x₃ = s, x₄ = t.
К1.35 б.
Дослідіть систему залежно від параметра k: x + y − z = 1
2x + 3y + kz = 3
x + ky + 3z = 2
Відповідь
R₂ − 2R₁: y + (k + 2)z = 1; R₃ − R₁: (k − 1)y + 4z = 1. Далі R₃ − (k − 1)R₂: (4 − (k − 1)(k + 2))z = 2 − k, тобто −(k + 3)(k − 2)z = 2 − k.
k ≠ 2, k ≠ −3: єдиний розв'язок x = 1, y = z = 1/(k + 3).
k = 2: 0 = 0, безліч розв'язків x = 5t, y = 1 − 4t, z = t.
k = −3: 0 = 5, розв'язків немає.
