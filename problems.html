Блок 1. СЛАР і метод Жордана–Гаусса

Розв'язання систем

1.1
Розв'яжіть методом Гаусса: 3x + 2y = 7
x − y = −1
Відповідь
x = 1, y = 2.
1.2
Запишіть розширену матрицю і розв'яжіть: x + y + z = 6
2x − y + z = 3
x + 2y − z = 2
Відповідь
x = 1, y = 2, z = 3. Перевірка підстановкою в усі три рівняння обов'язкова.
1.3
Розв'яжіть методом Жордана–Гаусса (доведіть ліву частину до одиничної): 2x − y + 3z = 14
x + y + z = 4
3x − 2y − z = 5
Відповідь
x = 2, y = −1, z = 3. Підказка: почніть з обміну R₁ ↔ R₂, щоб ведучим елементом була 1.
1.4
Дослідіть систему і розв'яжіть її, якщо вона сумісна: 1 2 -1 ¦ 1; 2 3 1 ¦ 4; 3 5 0 ¦ 6
Відповідь
Після зведення: 1 0 5 ¦ 0; 0 1 -3 ¦ 0; 0 0 0 ¦ 1. Рядок 0 0 0 | 1 означає 0 = 1, тому система несумісна. (R₃ − R₁ − R₂ дає це одразу.)
1.5
Знайдіть загальний розв'язок: x − y + 2z = 3
2x − y + 5z = 8
x + 3z = 5
Відповідь
Зведена форма: 1 0 3 ¦ 5; 0 1 1 ¦ 2; 0 0 0 ¦ 0, r = 2 < 3, одна вільна змінна.
x = 5 − 3t, y = 2 − t, z = t, t ∈ ℝ.
1.6
Знайдіть загальний розв'язок системи з 4 невідомими: x₁ + 2x₂ − x₄ = 1
2x₁ + 4x₂ + x₃ = 5
x₁ + 2x₂ + x₃ + x₄ = 4
Скільки вільних змінних? Наведіть один частинний розв'язок.
Відповідь
Зведена форма: 1 2 0 -1 ¦ 1; 0 0 1 2 ¦ 3; 0 0 0 0 ¦ 0. r = 2, вільних змінних 4 − 2 = 2 (x₂ = s, x₄ = t).
x₁ = 1 − 2s + t, x₂ = s, x₃ = 3 − 2t, x₄ = t. Частинний (s = t = 0): (1, 0, 3, 0).
1.7
Однорідна система x + 2y − z = 0
2x + 5y + z = 0
x + 3y + 2z = 0 Чи має вона нетривіальні розв'язки? Знайдіть їх усі.
Відповідь
det = 0 (рядок 3 = рядок 2 − рядок 1), тож так. Зведена форма: x − 7z = 0, y + 3z = 0.
x = 7t, y = −3t, z = t.
1.8
Розв'яжіть правилом Крамера: 5x − 3y = 7
2x + 4y = 8
Відповідь
Δ = 20 + 6 = 26, Δₓ = 28 + 24 = 52, Δ_y = 40 − 14 = 26. x = 2, y = 1.
1.9
Розв'яжіть правилом Крамера: x + y + 2z = 9
2x + 4y − 3z = 1
3x + 6y − 5z = 0
Відповідь
Δ = −1, Δₓ = −1, Δ_y = −2, Δ_z = −3. x = 1, y = 2, z = 3.

Системи з параметром

1.10
Дослідіть систему залежно від a: ax + y = 1
x + ay = 1
Відповідь
Δ = a² − 1.
a ≠ ±1: єдиний розв'язок x = y = 1/(a + 1).
a = 1: обидва рівняння x + y = 1, безліч розв'язків x = 1 − t, y = t.
a = −1: −x + y = 1 і x − y = 1, суперечність, розв'язків немає.
1.11
При яких k однорідна система з матрицею 1 2 3; 2 k 6; -1 3 k має нетривіальні розв'язки?
Відповідь
det = (k − 4)(k + 3) = 0, тобто k = 4 або k = −3.
1.12
Дослідіть систему залежно від a і розв'яжіть у кожному випадку: x + y + az = 1
x + ay + z = 1
ax + y + z = 1
Відповідь
det = −(a − 1)²(a + 2).
a ≠ 1, a ≠ −2: єдиний розв'язок x = y = z = 1/(a + 2).
a = 1: усі рівняння x + y + z = 1, безліч розв'язків (2 вільні змінні): x = 1 − s − t, y = s, z = t.
a = −2: після зведення з'являється рядок 0 0 0 | 1, розв'язків немає (додайте всі три рівняння: 0 = 3).
1.13
При яких a і b система x + 2y = 3
2x + ay = b (а) має єдиний розв'язок; (б) безліч; (в) жодного?
Відповідь
R₂ − 2R₁: (a − 4)y = b − 6.
(а) a ≠ 4; тоді y = (b − 6)/(a − 4), x = 3 − 2y.
(б) a = 4, b = 6.
(в) a = 4, b ≠ 6.

Стовпцева картина

1.14
Чи є вектор b лінійною комбінацією a₁ = (1, 3, −1) і a₂ = (2, 1, 4)? Розгляньте (а) b = (4, 7, 2); (б) b = (4, 7, 3). Сформулюйте відповідь мовою СЛАР.
Відповідь
(а) Так: b = 2a₁ + a₂ (система x·a₁ + y·a₂ = b сумісна, x = 2, y = 1).
(б) Ні: з перших двох координат x = 2, y = 1, але третя дає 2 ≠ 3, система несумісна.

Моделювання

1.15
У кав'ярні 2 капучино, 1 круасан і 3 сирники коштують 145 грн; 1 капучино, 3 круасани і 1 сирник — 95 грн; 3 капучино, 2 круасани і 2 сирники — 150 грн. Знайдіть ціну кожної позиції.
Відповідь
Капучино 20 грн, круасан 15 грн, сирник 30 грн.
1.16
Інвестор розподілив 20 000 грн між трьома фондами з річною дохідністю 4 %, 6 % і 8 %. Річний дохід становить 1240 грн, а в третій фонд вкладено втричі менше, ніж у перші два разом. Скільки вкладено в кожен фонд?
Відповідь
x + y + z = 20000; 0,04x + 0,06y + 0,08z = 1240; x + y = 3z.
3000 грн, 12 000 грн, 5000 грн. Перевірка: 120 + 720 + 400 = 1240.
1.17
Знайдіть параболу y = ax² + bx + c, що проходить через точки (−1, 6), (0, 1), (2, 3).
Відповідь
a − b + c = 6, c = 1, 4a + 2b + c = 3 ⇒ y = 2x² − 3x + 1.
1.18
Мережа доріг з одностороннім рухом (авто/год). На перехрестя A в'їжджає 500 авто, з нього виїжджають потоки x₁ і x₄. B: в'їжджає x₁, виїжджають x₂ і 200. C: в'їжджають x₂ і x₃, виїжджає 300. D: в'їжджає x₄, виїжджає x₃. На кожному перехресті «скільки в'їхало = скільки виїхало». Знайдіть усі можливі потоки. Яке найменше та найбільше значення x₄, якщо всі потоки невід'ємні?
Відповідь
x₁ + x₄ = 500, x₁ − x₂ = 200, x₂ + x₃ = 300, x₃ − x₄ = 0.
x₁ = 500 − t, x₂ = 300 − t, x₃ = t, x₄ = t. З x₂ ≥ 0 маємо 0 ≤ x₄ ≤ 300.
1.19додатково
Розв'яжіть у полі Z₅: x + 2y = 4
3x + 4y = 1
Відповідь
R₂ − 3R₁: −2y = −11, тобто 3y ≡ 4 (mod 5). 3⁻¹ = 2 у Z₅, тож y = 8 ≡ 3; x = 4 − 6 ≡ 3. Відповідь: x = 3, y = 3.

1.20
Розв'яжіть, спершу позбувшись дробів: x/2 + y/3 = 4
x − y = 3
Відповідь
3x + 2y = 24 і x − y = 3 ⇒ x = 6, y = 3.
1.21
Не розв'язуючи, визначте кількість розв'язків за зведеною розширеною матрицею (невідомі x, y, z):
  1. 1 2 0 ¦ 3; 0 1 4 ¦ 1; 0 0 2 ¦ 5
  2. 1 -1 3 ¦ 2; 0 0 1 ¦ 4; 0 0 0 ¦ 0
  3. 1 0 2 ¦ 1; 0 1 1 ¦ 0; 0 0 0 ¦ 7
Відповідь
a) r = 3 = n, єдиний розв'язок; b) сумісна, r = 2 < 3, безліч (одна вільна змінна, y); c) рядок 0 0 0 | 7, розв'язків немає.
1.22
Розв'яжіть систему з чотирма невідомими: x + y + z + w = 10
x − y + z − w = −2
2x + y − z + w = 5
x + 2y + 3z − w = 10
Відповідь
x = 1, y = 2, z = 3, w = 4. Підказка: R₁ + R₂ дає x + z = 4.
1.23
Для яких правих частин (b₁, b₂, b₃) сумісна система з матрицею 1 2 1; 2 5 3; 1 3 2?
Відповідь
det = 0, а R₃ = R₂ − R₁. Отже, система сумісна ⇔ b₃ = b₂ − b₁. Геометрично: b має лежати в площині, натягнутій на стовпці.
1.24
Знайдіть усі розв'язки однорідної системи і запишіть їх як лінійну комбінацію двох векторів: x₁ + x₂ − 2x₃ + x₄ = 0
2x₁ + 3x₂ − x₃ + 4x₄ = 0
Відповідь
Зведена форма: x₁ − 5x₃ − x₄ = 0, x₂ + 3x₃ + 2x₄ = 0.
x = s·(5, −3, 1, 0) + t·(1, −2, 0, 1), s, t ∈ ℝ.
1.25
Дослідіть систему залежно від λ: x + y + z = 1
x + 2y + λz = 2
x + 4y + λ²z = 4
Відповідь
det = (λ − 1)(λ − 2).
λ ≠ 1, 2: єдиний розв'язок (0, 1, 0).
λ = 1: безліч, x = −t, y = 1, z = t.
λ = 2: безліч, x = 0, y = 1 − t, z = t.
Несумісних випадків немає: (0, 1, 0) завжди розв'язок.
1.26
Скільки грамів 10 % і 30 % розчинів треба змішати, щоб отримати 200 г 25 % розчину?
Відповідь
x + y = 200, 0,1x + 0,3y = 50 ⇒ 50 г 10 % і 150 г 30 %.
1.27
Ринок двох товарів: попит Q₁ = 10 − 2P₁ + P₂, пропозиція Q₁ = −2 + 3P₁; попит Q₂ = 19 + P₁ − P₂, пропозиція Q₂ = −1 + 2P₂. Знайдіть рівноважні ціни й обсяги.
Відповідь
5P₁ − P₂ = 12, −P₁ + 3P₂ = 20 ⇒ P₁ = 4, P₂ = 8; Q₁ = 10, Q₂ = 15.
1.28
Зрівняйте реакцію горіння пропану x C₃H₈ + y O₂ → z CO₂ + w H₂O, склавши однорідну систему (баланс C, H, O). Знайдіть найменші натуральні коефіцієнти.
Відповідь
C: 3x = z; H: 8x = 2w; O: 2y = 2z + w. Розв'язок t·(1, 5, 3, 4): C₃H₈ + 5O₂ → 3CO₂ + 4H₂O.
1.29
Модель Леонтьєва: дві галузі, матриця прямих витрат A = 0.2 0.3; 0.4 0.1, кінцевий попит d = (60, 30). Знайдіть валовий випуск x із рівняння x = Ax + d.
Відповідь
(I − A)x = d: 0,8x₁ − 0,3x₂ = 60, −0,4x₁ + 0,9x₂ = 30 ⇒ x = (105, 80).
1.30
Знайдіть кубічний многочлен p(x) = ax³ + bx² + cx + d, для якого p(−1) = −4, p(0) = 1, p(1) = 2, p(2) = 5.
Відповідь
p(x) = x³ − 2x² + 2x + 1.

Блок 2. Вектори й матриці

Вектори і простори

2.1
Виразіть v = (4, 5, 1) через a₁ = (1, 2, −1) і a₂ = (2, 1, 3).
Відповідь
v = 2a₁ + a₂.
2.2
При якому k вектори (1, 2, 3), (2, −1, 1), (k, 1, 4) лінійно залежні? Для цього k знайдіть явну залежність.
Відповідь
det = 5(k − 3), тож k = 3. Тоді (3, 1, 4) = (1, 2, 3) + (2, −1, 1).
2.3
Які з множин є підпросторами? Обґрунтуйте кожну.
  1. {(x, y, z) ∈ ℝ³ : x − 2y + z = 0}
  2. {(x, y) : x + y = 1}
  3. {(x, y) : x ≥ 0}
  4. {(t, 2t, 3t) : t ∈ ℝ}
  5. {(x, y) : x² = y²}
  6. матриці 2×2 з det = 0
  7. верхньотрикутні матриці 3×3
Відповідь
a) так; b) ні, нуля немає; c) ні, (1, 0)·(−1) = (−1, 0) ∉; d) так (пряма через 0); e) ні: (1, 1) + (1, −1) = (2, 0) ∉; f) ні: 1 0; 0 0 + 0 0; 0 1 = I, det I = 1; g) так.

Операції

2.4
A = 1 -2; 3 0; 2 1, B = 2 1 0; -1 4 3. Обчисліть 2A − 3Bᵀ.
Відповідь
-4 -1; 3 -12; 4 -7
2.5
A — 2×3, B — 3×3, C — 3×1, D — 1×2. Які добутки існують і якого розміру: AB, BA, AC, CD, DA, DC, BAᵀ, CᵀC, CCᵀ?
Відповідь
AB: 2×3; BA: ні; AC: 2×1; CD: 3×2; DA: 1×3; DC: ні; BAᵀ: 3×2; CᵀC: 1×1 (число); CCᵀ: 3×3.
2.6
A = 1 2; 3 4, B = 0 1; 1 0. Знайдіть AB і BA. Що робить множення на B справа і зліва?
Відповідь
AB = 2 1; 4 3 (переставлено стовпці A), BA = 3 4; 1 2 (переставлено рядки A). AB ≠ BA.
2.7
Обчисліть 2 -1 0; 1 3 2·3; 1; -2 двома способами: «рядок на стовпець» і як лінійну комбінацію стовпців.
Відповідь
3·(2, 1) + 1·(−1, 3) − 2·(0, 2) = (5, 2).
2.8
D = diag(2, −1, 3), A = 1 1; 2 0; 0 4. Знайдіть DA і A·diag(1, 5), не множачи «в лоб».
Відповідь
DA масштабує рядки: 2 2; -2 0; 0 12. A·diag(1, 5) масштабує стовпці: 1 5; 2 0; 0 20.
2.9
Знайдіть x, y, z, w: 2x+y x−y; x+z 3w−z = 5 1; 4 4.
Відповідь
x = 2, y = 1, z = 2, w = 2.
2.10
Два магазини за день продали товари (рядки — магазини, стовпці — хліб, сир, кава): Q = 10 4 6; 8 5 2. Ціни p = (12, 20, 15) грн. Яким добутком виражається виторг кожного магазину? Обчисліть.
Відповідь
Q·p = (290, 226) грн.
2.11
A = 1 -1; 2 0, B = 1 0; 3 1. Обчисліть (A + B)² і A² + 2AB + B². Чому вони різні? Знайдіть AB і BA.
Відповідь
(A + B)² = -1 -3; 15 -4, A² + 2AB + B² = -4 -3; 12 -1. AB = -2 -1; 2 0, BA = 1 -1; 5 -3. Правильно: (A + B)² = A² + AB + BA + B², а AB ≠ BA.
2.12
Наведіть приклад ненульових матриць 2×2 A і B, для яких AB = O.
Відповідь
Наприклад, A = 1 1; 1 1, B = 1 -1; -1 1. Обидві вироджені; так буває завжди, коли AB = O при ненульових A, B.
2.13
Для A = 1 2 0; 0 1 -1; 2 0 1 обчисліть AᵀA. Доведіть, що AᵀA симетрична для будь-якої A.
Відповідь
AᵀA = 5 2 2; 2 5 -1; 2 -1 2. (AᵀA)ᵀ = Aᵀ(Aᵀ)ᵀ = AᵀA.
2.14
Подайте A = 1 4 -2; 0 3 5; 6 1 2 як суму симетричної та кососиметричної матриць.
Відповідь
S = (A + Aᵀ)/2 = 1 2 2; 2 3 3; 2 3 2, K = (A − Aᵀ)/2 = 0 2 -4; -2 0 2; 4 -2 0.
2.15
Місто і передмістя: щороку 10 % жителів міста переїжджають у передмістя, а 20 % жителів передмістя — у місто. Зараз (у тисячах) x₀ = (600, 400). Запишіть матрицю переходу P і знайдіть розподіл через 1 і 2 роки.
Відповідь
P = 0.9 0.2; 0.1 0.8, x₁ = Px₀ = (620, 380), x₂ = Px₁ = (634, 366).

2.24

Підсумкова оцінка: тести мають ваги 0,2, 0,3 і 0,5. Бали студентів (рядки) за тести (стовпці): 80 70 90; 60 90 85; 95 80 70. Запишіть підсумки як добуток матриці на вектор і обчисліть.
Відповідь
