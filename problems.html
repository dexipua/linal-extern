1.3

3x − 2y − z = 5
Відповідь

1.4
Дослідіть систему і розв'яжіть її, якщо вона сумісна: 1 2 -1 ¦ 1; 2 3 1 ¦ 4; 3 5 0 ¦ 6
Відповідь
Після зведення: 1 0 5 ¦ 0; 0 1 -3 ¦ 0; 0 0 0 ¦ 1. Рядок 0 0 0 | 1 означає 0 = 1, тому система несумісна. (R₃ − R₁ − R₂ дає це одразу.)
1.5
Знайдіть загальний розв'язок: x − y + 2z = 3
2x − y + 5z = 8
x + 3z = 5
Відповідь
Зведена форма: 1 0 3 ¦ 5; 0 1 1 ¦ 2; 0 0 0 ¦ 0, r = 2 < 3, одна вільна змінна.
x = 5 − 3t, y = 2 − t, z = t, t ∈ ℝ.
1.6
Знайдіть загальний розв'язок системи з 4 невідомими: x₁ + 2x₂ − x₄ = 1
2x₁ + 4x₂ + x₃ = 5
x₁ + 2x₂ + x₃ + x₄ = 4
Скільки вільних змінних? Наведіть один частинний розв'язок.
Відповідь
Зведена форма: 1 2 0 -1 ¦ 1; 0 0 1 2 ¦ 3; 0 0 0 0 ¦ 0. r = 2, вільних змінних 4 − 2 = 2 (x₂ = s, x₄ = t).
x₁ = 1 − 2s + t, x₂ = s, x₃ = 3 − 2t, x₄ = t. Частинний (s = t = 0): (1, 0, 3, 0).
1.7
Однорідна система x + 2y − z = 0
2x + 5y + z = 0
x + 3y + 2z = 0 Чи має вона нетривіальні розв'язки? Знайдіть їх усі.
Відповідь
det = 0 (рядок 3 = рядок 2 − рядок 1), тож так. Зведена форма: x − 7z = 0, y + 3z = 0.
x = 7t, y = −3t, z = t.
1.8

Відповідь

1.9

Системи з параметром

1.10
Дослідіть систему залежно від a: ax + y = 1
x + ay = 1
Відповідь
Δ = a² − 1.
a ≠ ±1: єдиний розв'язок x = y = 1/(a + 1).
a = 1: обидва рівняння x + y = 1, безліч розв'язків x = 1 − t, y = t.
a = −1: −x + y = 1 і x − y = 1, суперечність, розв'язків немає.
1.11
При яких k однорідна система з матрицею 1 2 3; 2 k 6; -1 3 k має нетривіальні розв'язки?
Відповідь
det = (k − 4)(k + 3) = 0, тобто k = 4 або k = −3.
1.12
Дослідіть систему залежно від a і розв'яжіть у кожному випадку: x + y + az = 1
x + ay + z = 1
ax + y + z = 1
Відповідь
det = −(a − 1)²(a + 2).
a ≠ 1, a ≠ −2: єдиний розв'язок x = y = z = 1/(a + 2).
a = 1: усі рівняння x + y + z = 1, безліч розв'язків (2 вільні змінні): x = 1 − s − t, y = s, z = t.
a = −2: після зведення з'являється рядок 0 0 0 | 1, розв'язків немає (додайте всі три рівняння: 0 = 3).
1.13
При яких a і b система x + 2y = 3
2x + ay = b (а) має єдиний розв'язок; (б) безліч; (в) жодного?
Відповідь
R₂ − 2R₁: (a − 4)y = b − 6.
(а) a ≠ 4; тоді y = (b − 6)/(a − 4), x = 3 − 2y.
(б) a = 4, b = 6.
(в) a = 4, b ≠ 6.

Стовпцева картина

1.14
Чи є вектор b лінійною комбінацією a₁ = (1, 3, −1) і a₂ = (2, 1, 4)? Розгляньте (а) b = (4, 7, 2); (б) b = (4, 7, 3). Сформулюйте відповідь мовою СЛАР.
Відповідь
(а) Так: b = 2a₁ + a₂ (система x·a₁ + y·a₂ = b сумісна, x = 2, y = 1).
(б) Ні: з перших двох координат x = 2, y = 1, але третя дає 2 ≠ 3, система несумісна.

Знайдіть ортогональну проєкцію й ортогональну складову x = (4, −1, −3, 4) щодо U = Lin((1, 1, 1, 1), (1, 2, 2, −1), (1, 0, 0, 3)).

a₃ = 2a₁ − a₂, тож беремо базис a₁, a₂. Нормальні рівняння дають p = (1, −1, −1, 5), h = x − p = (3, 0, −2, −1). Перевірка: h·a₁ = h·a₂ = 0.
7.14
Знайдіть відстань від x = (7, −3, −1) до підпростору Lin((1, 1, 1), (4, 0, 5)).
Відповідь
Ортогональна складова h = (5, −1, −4) (вона перпендикулярна обом векторам), відстань ‖h‖ = √42.
7.15
Знайдіть кут між x = (2, 2, 1, 1) і U = Lin((3, 4, −4, −1), (0, 1, −1, 2)).
Відповідь
Проєкція p = (½, 1, −1, ½), x·p = 5/2, ‖x‖ = √10, ‖p‖ = √(5/2). cos φ = 2,5/(√10·√2,5) = 2,5/5 = ½, φ = 60°.
7.16
Методом найменших квадратів знайдіть пряму y = a + bx, найближчу до точок (0, 1), (1, 3), (2, 4), (3, 4).
Відповідь
AᵀA = 4 6; 6 14, Aᵀb = (12, 23) ⇒ a = 3/2, b = 1: y = 1,5 + x.
7.17
Доведіть, що діагональ n-вимірного куба утворює однаковий кут з усіма ребрами. Знайдіть його та границю при n → ∞.
Відповідь
Діагональ (1, …, 1), ребро eᵢ: cos φ = 1/√n для кожного i. φ = arccos(1/√n) → 90°: у великих розмірностях діагональ «майже перпендикулярна» всім осям.

Блок 8. Поглиблено: лінійні перетворення

Оператори та їх матриці

8.1
Чи лінійні перетворення ℝ³: 1) (x₂ + x₃, 2x₁ + x₃, 3x₁ − x₂ + x₃); 2) (x₁, x₂ + 1, x₃ + 2); 3) (2x₁ + x₂, x₁ + x₃, x₃²)? Для лінійного запишіть матрицю.
Відповідь
1) так, матриця 0 1 1; 2 0 1; 3 -1 1; 2) ні: 0 ↦ (0, 1, 2); 3) ні: x₃² не лінійне.
8.2
Запишіть матриці відображення й ортогональної проєкції ℝ³ щодо площини Lin((1, 1, 0), (0, 0, 1)).
Відповідь
Одинична нормаль n = (1, −1, 0)/√2. Відображення I − 2nnᵀ = 0 1 0; 1 0 0; 0 0 1, проєкція I − nnᵀ = 1/2 1/2 0; 1/2 1/2 0; 0 0 1.
8.3
Знайдіть композицію симетрій площини відносно Ox і Oy, а потім у загальному вигляді ΣαΣβ.
Відповідь
σₓσᵧ = 1 0; 0 -1-1 0; 0 1 = −I — поворот на 180°. Загалом ΣαΣβ = P2(α−β): поворот на подвоєний кут між осями.
8.4
Знайдіть ядро й образ оператора з матрицею 4 -5 2; 5 -7 3; 6 -9 4.
Відповідь
rank = 2. Ker = Lin((1, 2, 3)), Im = Lin((4, 5, 6), (−5, −7, −9)). dim Ker + dim Im = 1 + 2 = 3.

Заміна базису й подібність

8.5
Знайдіть матрицю симетрії відносно y = x у базисі (1, 1), (1, −1), обчисливши P⁻¹SP. Поясніть результат.
Відповідь
P⁻¹SP = 1 0; 0 -1. (1, 1) лежить на осі й не змінюється, (1, −1) перпендикулярний і перевертається.
8.6
Оператор має в базисі e матрицю 1 1 1; -1 1 -1; 0 0 1. Знайдіть його матрицю в базисі f₁ = e₁, f₂ = e₁ + e₂, f₃ = e₁ + e₂ + e₃.
Відповідь
T = 1 1 1; 0 1 1; 0 0 1, Af = T⁻¹AeT = 2 2 4; -1 0 -2; 0 0 1. Контроль: слід 3 і det 2 в обох базисах.
8.7
Доведіть, що подібні матриці A і B = P⁻¹AP мають однакові визначник і характеристичний многочлен.
Відповідь
det B = det P⁻¹·det A·det P = det A. B − λI = P⁻¹(A − λI)P, тож det(B − λI) = det(A − λI).

Власні значення й вектори

8.8
Знайдіть власні значення та власні вектори 2 1; 1 2.
Відповідь
λ² − 4λ + 3 = 0: λ = 1 з вектором (1, −1), λ = 3 з вектором (1, 1).
8.9
Знайдіть власні значення та власні вектори 4 1; 2 3.
Відповідь
λ² − 7λ + 10 = 0: λ = 2 з вектором (1, −2), λ = 5 з вектором (1, 1).
8.10
Доведіть, що поворот на 90° не має дійсних власних значень. Знайдіть власні значення і вектори симетрії відносно Ox.
Відповідь
det(R − λI) = λ² + 1 = 0 не має дійсних коренів. Симетрія: λ = 1 з вектором (1, 0), λ = −1 з вектором (0, 1).
8.11
Знайдіть власні значення та власні вектори 2 0 0; 0 3 4; 0 4 -3.
Відповідь
(2 − λ)(λ² − 25) = 0: λ = 2 з вектором (1, 0, 0), λ = 5 з вектором (0, 2, 1), λ = −5 з вектором (0, −1, 2). Вектори попарно ортогональні, бо матриця симетрична.
8.12
Власні значення матриці A 2×2 дорівнюють 2 і −3. Знайдіть tr A, det A, det(A²) і власні значення A⁻¹.
Відповідь
tr A = −1, det A = −6, det(A²) = 36, власні значення A⁻¹: 1/2 і −1/3.
8.13
Знайдіть власні значення та власні вектори -1 3 -1; -3 5 -1; -3 3 1.
Відповідь
χ(λ) = −(λ − 1)(λ − 2)². λ = 1: (1, 1, 1); λ = 2: двовимірний V₂ = Lin((1, 1, 0), (−1, 0, 3)). Геометрична кратність 2 збігається з алгебраїчною.
8.14
З геометричних міркувань знайдіть власні значення й вектори: 1) поворот ℝ³ навколо Ox на кут α (0 < α < π); 2) проєкція ℝ³ на площину Lin((1, 1, 0), (0, 0, 1)).
Відповідь
1) λ = 1 з (1, 0, 0) — вісь; інших дійсних немає. 2) λ = 1 з V₁ = сама площина, λ = 0 з нормаллю (1, −1, 0).
8.15
Доведіть: якщо A² = A, то кожне власне значення A дорівнює 0 або 1.
Відповідь
Av = λv ⇒ A²v = λ²v. Але A²v = Av = λv, тож (λ² − λ)v = 0, а v ≠ 0 ⇒ λ = 0 або 1.

Діагоналізація

8.16
Діагоналізуйте 4 -1; 2 1.
Відповідь
λ² − 5λ + 6 = 0: λ = 2 з (1, 2), λ = 3 з (1, 1). P = 1 1; 2 1, D = diag(2, 3), A = PDP⁻¹.
8.17
Діагоналізуйте A = 2 1; 1 2 і знайдіть формулу для Aⁿ. Перевірте для n = 4.
Відповідь
P = 1 1; -1 1, D = diag(1, 3). Aⁿ = PDⁿP⁻¹ = ½·3ⁿ+1 3ⁿ−1; 3ⁿ−1 3ⁿ+1. A⁴ = 41 40; 40 41.
8.18
Доведіть, що 1 1; 1 0ⁿ = Fₙ₊₁ Fₙ; Fₙ Fₙ₋₁ (числа Фібоначчі). Знайдіть 10-й степінь і власні значення матриці.
Відповідь
Індукція: множення на матрицю справа дає Fₙ₊₁ + Fₙ = Fₙ₊₂. A¹⁰ = 89 55; 55 34. λ = (1 ± √5)/2 — звідси формула Біне.
8.19
Чи діагоналізовна 4 -5 2; 5 -7 3; 6 -9 4?
Відповідь
χ(λ) = −λ²(λ − 1). λ = 0 має алгебраїчну кратність 2, але rank A = 2, тож dim V₀ = 1. Ні, не діагоналізовна.
8.20
Діагоналізуйте -5 0 6; -3 1 3; -4 0 5 і знайдіть A¹⁰⁰.
Відповідь
λ = 1 (кратність 2): (0, 1, 0), (1, 0, 1); λ = −1: (6, 3, 4). Обидві кратності збігаються, тож A = PDP⁻¹ з D = diag(1, 1, −1). D¹⁰⁰ = I, тому A¹⁰⁰ = I (і справді A² = I).
8.21
Зведіть до головних осей 0 2 2; 2 3 -1; 2 -1 3.
Відповідь
λ = 4 (кратність 2), λ = −2. Ортонормовані власні вектори: (1, 1, 1)/√3 і (0, 1, −1)/√2 для 4; (−2, 1, 1)/√6 для −2. S = QΛQᵀ, Λ = diag(4, 4, −2), Q — матриця з цих стовпців.
8.22
Перевірте теорему Гамільтона–Келі A² − (tr A)A + (det A)I = O для A = 1 2; 3 4 і виведіть з неї A⁻¹.
Відповідь
tr A = 5, det A = −2: A² − 5A − 2I = O (це задача 2.18). A⁻¹ = (5I − A)/(−2) = (A − 5I)/2 = -2 1; 3/2 -1/2.
