Теорія

Конспект

Блоки 1–4 — чотири теми силабуса в порядку курсу: СЛАР → матриці → визначники й обернена → геометрія. Абзаци «Додатково» і блок 5 з'являються в режимі «Супер», блоки 6–8 — у «Поглибленому»; для тестів вони не обов'язкові.

Орієнтовний час (≈ 4,5 год): Блок 1 — 60 хв · Блок 2 — 50 хв · Блок 3 — 70 хв · Блок 4 — 30 хв · пробний тест — 60 хв.
Метод: читаєте блок → відповідаєте на «чекпоінти» → розв’язуєте задачі цього блоку з файлу практики → лише потім розкриваєте розв’язки. Ви вже знаєте метод Гауса, транспонування, діагональні матриці, множення «рядок на стовпець», додавання й множення на скаляр, тому тут ці теми лише згадані.

Блок 1. СЛАР і метод Жордана–Гаусса

Дві картини однієї системи

Рядкова: кожне рівняння — пряма (на площині) або площина (у просторі); розв’язок — їхній спільний перетин. Стовпцева: Ax = x₁a₁ + … + xₙaₙ, тож система розв’язна тоді й лише тоді, коли b є лінійною комбінацією стовпців A, а розв’язок — коефіцієнти цієї комбінації. Друга картина пояснює майже все далі (залежність, ранг, обернену).

Алгоритм

  1. Запишіть [A | b].
  2. Прямий хід: для кожного стовпця оберіть ведучий елемент (краще ±1; для цього міняйте рядки), занулюйте все під ним.
  3. Зворотний хід: занулюйте елементи над ведучими, діліть рядки, щоб ведучі стали 1.
  4. Читайте відповідь. Дозволені дії: поміняти рядки; помножити рядок на число ≠ 0; додати до рядка інший, помножений на число. Вони не змінюють множини розв’язків.

Після зведенняВисновок
з’явився рядок 0 … 0 | c, c ≠ 0несумісна, розв’язків немає

Однорідна система (b = 0) завжди має розв’язок x = 0. Нетривіальні розв’язки є ⇔ r < n; для квадратної матриці це ⇔ det A = 0.

Системи з параметром

Зводьте матрицю не ділячи на вираз із параметром. В останньому рядку отримаєте (щось)·z = (щось). Розгляньте окремо: коефіцієнт ≠ 0 (єдиний розв’язок), коефіцієнт = 0 і права частина ≠ 0 (нема), обидва = 0 (безліч). Для квадратної системи швидкий шлях: знайдіть det як функцію параметра, його нулі — «підозрілі» значення; їх розбирайте окремо.

Моделювання (типові задачі на тестах)

1) Оберіть невідомі (ціни, суми вкладів). 2) На кожну умову — рівняння. 3) Розв’яжіть. 4) Перевірте підстановкою в текстову умову й дайте відповідь словами з одиницями.

Правило Крамера (для квадратної системи з Δ = det A ≠ 0): xⱼ = Δⱼ/Δ, де Δⱼ — визначник, у якому j-й стовпець замінено на b. Для 2×2: Δ = a₁₁a₂₂ − a₁₂a₂₁. Практично Гаус швидший, Крамер зручний для 2×2 і для параметрів.

Чекпоінти блоку 1

1) Як за ступінчатим виглядом побачити, що система несумісна? Рядок 0…0 | c, c ≠ 0.
2) Система 3×3 має r = 2 і сумісна. Скільки вільних змінних? 3 − 2 = 1.
3) Чому однорідна система ніколи не несумісна? x = 0 завжди розв’язок.

Блок 2. Вектори й матриці

Вектори, лінійна комбінація, залежність

Вектори додаються й множаться на число поелементно. Лінійна комбінація α₁a₁ + … + αₖaₖ. Система лінійно залежна, якщо існує комбінація з не всіма нульовими коефіцієнтами, що дорівнює 0; рівносильно, один вектор виражається через решту. Практичний тест: складіть матрицю зі стовпців і зведіть її; якщо ранг < кількості векторів — залежні. Для n векторів у ℝⁿ: залежні ⇔ det = 0.

Підпростір

Підмножина W ⊂ V — підпростір, якщо (1) 0 ∈ W (найшвидша перевірка на «ні»), (2) a + b ∈ W для a, b ∈ W, (3) λa ∈ W. Приклади: {x + y + z = 0} — так; {x + y + z = 1} — ні (нема нуля); {xy = 0} — ні (не замкнена за додаванням); лінійна оболонка будь-яких векторів — так. Множини симетричних, діагональних, верхньотрикутних матриць — підпростори Mat(n, ℝ).

Типи матриць

Діагональна, скалярна λI, одинична I, верхня/нижня трикутна; симетрична S = Sᵀ; кососиметрична K = −Kᵀ (на діагоналі нулі).

Множення: розуміння

Розміри: (m×n)(n×p) → m×p, внутрішні розміри збігаються. Чотири погляди на AB:

  • рядок × стовпець: cᵢⱼ = (рядок i матриці A)·(стовпець j матриці B);
  • «стовпчиками»: j-й стовпець AB = A·(j-й стовпець B) — лінійна комбінація стовпців A з коефіцієнтами з bj;
  • «рядками»: i-й рядок AB = (i-й рядок A)·B — лінійна комбінація рядків B;
  • стовпець × рядок: AB = сума добутків (стовпець k матриці A)·(рядок k матриці B).
Приклад: 1 0 1; 1 0 1; 1 0 1·1; 2; 3 = 1·(стовпець 1) + 2·(стовпець 2) + 3·(стовпець 3) = 4; 4; 4.

Властивості

  • (AB)C = A(BC); A(B+C) = AB + AC; AI = IA = A.
  • AB ≠ BA загалом (обидва добутки можуть навіть мати різні розміри). Причина: AB — «спочатку B, потім A», порядок перетворень важливий.
  • (AB)ᵀ = BᵀAᵀ; (A+B)ᵀ = Aᵀ+Bᵀ; (λA)ᵀ = λAᵀ.
  • AB = O не означає, що A = O або B = O. Також (A+B)² ≠ A² + 2AB + B², а = A² + AB + BA + B².
  • Діагональна матриця D: DA масштабує рядки A, AD масштабує стовпці.
  • AᵀA і AAᵀ завжди визначені, квадратні й симетричні.
  • Матриця, що комутує з усіма матрицями порядку n, — скалярна (λI).

Степені та многочлени від матриці

Обчисліть Aᵏ для k = 2, 3, виведіть закономірність, доведіть індукцією. Наприклад, 1 1; 0 1n = 1 n; 0 1. Многочлен f(A) = A³ − 3A + 2I: вільний член множиться на I.

Чекпоінти блоку 2

1) A — 2×3, B — 3×4. Які розміри AB? Чи існує BA? 2×4; ні (4 ≠ 2).
2) Чи завжди (A+B)(A−B) = A² − B²? Ні: = A² − AB + BA − B².
3) Як записати Ax через стовпці A? x₁a₁ + … + xₙaₙ.

Блок 3. Визначники й обернена матриця

Обчислення

  • 2×2: ad − bc.
  • 3×3 (Саррюс): a₁₁a₂₂a₃₃ + a₁₂a₂₃a₃₁ + a₁₃a₂₁a₃₂ − a₁₃a₂₂a₃₁ − a₁₂a₂₁a₃₃ − a₁₁a₂₃a₃₂. Правило Саррюса — лише для 3×3.
  • Розклад за рядком/стовпцем: det A = Σⱼ aᵢⱼAᵢⱼ, Aᵢⱼ = (−1)i+j·Mᵢⱼ, де Mᵢⱼ — мінор (викреслили рядок i і стовпець j). Знаки — «шахівниця» + − + / − + − / + − +. Обирайте рядок із найбільшою кількістю нулів.
  • Зведення до трикутної матриці (найкраще для 4×4 і більше): det = добуток діагоналі, але обмін рядків міняє знак, множення рядка на k множить det на k, а додавання кратного іншого рядка det не змінює.

Властивості

det Aᵀ = det Adet(AB) = det A · det B
det(kA) = kⁿ det Adet A⁻¹ = 1/det A
обмін двох рядків: знак «−»два однакові/пропорційні рядки: det = 0
нульовий рядок: det = 0рядок · k ⇒ det · k
додати до рядка кратне іншого: det не змінюєтьсяdet(A+B) ≠ det A + det B

Усі властивості рядків справедливі й для стовпців. det трикутної матриці = добуток діагоналі; det I = 1.

Що означає det

|det A| — у скільки разів перетворення x ↦ Ax змінює площі (у 3D — об’єми). Знак «−» означає зміну орієнтації (дзеркальність). det = 0 — площина «схлопується» на пряму чи точку: інформація втрачається, оберненого перетворення немає.

Критерій невиродженості. Для квадратної A рівносильні: det A ≠ 0 ⇔ A⁻¹ існує ⇔ rank A = n ⇔ стовпці (рядки) лінійно незалежні ⇔ Ax = 0 має лише розв’язок x = 0 ⇔ Ax = b має єдиний розв’язок для кожного b.

Обернена матриця: три способи

  1. 2×2: a b; c d−1 = (1/(ad−bc))·d -b; -c a.
  2. Жордан–Гаус: [A | I] → [I | A⁻¹]. Основний спосіб для 3×3 і більше. Якщо зліва виник нульовий рядок, A вироджена.
  3. Через приєднану: A⁻¹ = (1/det A)·adj A, де adj A — транспонована матриця алгебраїчних доповнень. Корисно для теорії.

Властивості: (AB)⁻¹ = B⁻¹A⁻¹ (порядок змінюється!); (Aᵀ)⁻¹ = (A⁻¹)ᵀ; (A⁻¹)⁻¹ = A; обернена єдина. Перевірка: AA⁻¹ = I.

Розв’язання через обернену

Ax = b ⇒ x = A⁻¹b. Матричні рівняння: AX = B ⇒ X = A⁻¹B (A⁻¹ зліва); XA = B ⇒ X = BA⁻¹ (A⁻¹ справа). Порядок множників критичний.

Додатково: A·adj A = det A·I; det(adj A) = (det A)ⁿ⁻¹; обертовні матриці утворюють групу GL(n, F); подібні матриці B = T⁻¹AT мають однаковий det; ортогональна матриця (QᵀQ = I) має det = ±1; визначник Вандермонда дорівнює ∏(xᵢ − xⱼ), i > j.

Чекпоінти блоку 3

1) A — 3×3, det A = 5. Чому дорівнює det(2A)? 8·5 = 40.
2) Чому (AB)⁻¹ = B⁻¹A⁻¹? (AB)(B⁻¹A⁻¹) = A(BB⁻¹)A⁻¹ = AA⁻¹ = I.
3) Що означає det = 0 геометрично? Площі «схлопуються» в нуль, перетворення незворотне.

Блок 5. Супер: інструменти глибше

Режим «Супер». Це повторення блоків 1–4 на рівні, вищому за силабус. Матеріал іде за розділом 1 другої частини курсу «Інструменти лінійної алгебри»: підстановки, спеціальні визначники, геометрія через визначник, векторний і мішаний добутки, алгебраїчні структури. На тестах курсу таке трапляється хіба що як «зірочка», зате воно сильно прокачує техніку.

Матриці як перетворення простору, блочні матриці

Матриця 3×3 так само задає перетворення простору x ↦ Ax, а її стовпці є образами i, j, k. Корисні приклади: проєкція на площину XY 1 0 0; 0 1 0; 0 0 0, поворот навколо Oz на кут φ cos φ -sin φ 0; sin φ cos φ 0; 0 0 1 і гомотетія kI. Добуток AB відповідає композиції: спочатку діє B, потім A, бо (AB)x = A(Bx).

Афінні відображення x ↦ Ax + b вже не лінійні, бо 0 переходить у b. Саме вони будують фрактали. Трикутник Серпінського отримують, якщо до кожної точки множини застосувати три відображення: Ax, Ax + b, Ax + c з A = ½I, b = (½, 0), c = (0, ½). Якщо записати точки стовпцями матриці X, то всі образи Ax дає один добуток AX.

Блочні матриці множаться «блоками», як звичайні, якщо розміри блоків узгоджені. Наприклад, для A розміру m×n матриця K = I Aᵀ; A O квадратна порядку n + m і симетрична; тут I має розмір n×n, а O має розмір m×m. Якщо матриця блочно-трикутна, то det A B; O D = det A · det D.

Підстановки та їх парність

Підстановка σ ∈ Sₙ — це взаємно однозначне відображення {1, …, n} → {1, …, n}, і всього їх n!. Добуток στ означає «спочатку τ, потім σ»: (στ)(i) = σ(τ(i)). Обернену σ⁻¹ отримують, якщо поміняти рядки запису місцями й упорядкувати стовпці.

  • Цикли. Кожна підстановка розкладається в добуток незалежних циклів: 1 → σ(1) → σ(σ(1)) → …, доки не повернемося до 1. Порядок підстановки (найменше k, для якого σᵏ = id) дорівнює НСК довжин циклів. Тому σ²⁰⁰ = σ200 mod порядок.
  • Парність. Інверсія — це пара i < j з σ(i) > σ(j). Підстановка парна, якщо інверсій парна кількість. Швидший спосіб через цикли: sgn σ = (−1)n − (кількість циклів), а цикл довжини k є добутком k − 1 транспозицій.
  • Зв'язок з визначником: det A = Σ sgn σ · a1σ(1)…anσ(n), тобто сума за всіма n! підстановками. Звідси одразу видно, що det Aᵀ = det A, а обмін двох рядків міняє знак, бо множить кожну підстановку на транспозицію.

Спеціальні визначники

  • Тридіагональний визначник Dₙ з a на діагоналі, b над нею і c під нею: розклад за першим рядком дає рекурентну формулу Dₙ = a·Dₙ₋₁ − bc·Dₙ₋₂. Її розв'язують, як лінійну рекуренту, через корені t² = at − bc. Приклад: a = 5, b = 3, c = 2 дають Dₙ = 3ⁿ⁺¹ − 2ⁿ⁺¹.
  • Вандермонд: визначник з рядками (1, xᵢ, xᵢ², …, xᵢⁿ⁻¹) дорівнює ∏i>j(xᵢ − xⱼ). Він ненульовий ⇔ усі xᵢ різні. Звідси випливає, що через n точок з різними x проходить рівно один многочлен степеня < n.
  • «Усі однакові, крім діагоналі». Додайте всі рядки до першого й винесіть спільний множник, потім відніміть перший рядок від решти. Наприклад, матриця з нулями на діагоналі й одиницями поза нею має det = (−1)ⁿ⁻¹(n − 1).
  • Блочно-трикутний: det = добуток визначників діагональних блоків.

Геометрія через визначник

Визначник дорівнює нулю ⇔ рядки лінійно залежні. Звідси маємо готові рівняння.

УмоваВизначник
A, B, C на одній прямійx₁ y₁ 1; x₂ y₂ 1; x₃ y₃ 1 = 0
пряма через A, Bx y 1; x₁ y₁ 1; x₂ y₂ 1 = 0

Площа трикутника на площині дорівнює ½·|det(B − A, C − A)|. Рівняння кола після обчислення визначника зведіть до вигляду (x − a)² + (y − b)² = r², виділивши повні квадрати.

Векторний і мішаний добутки

Векторний добуток a × b — це вектор, перпендикулярний a і b, з довжиною |a||b| sin φ (площа паралелограма), такий, що трійка a, b, a × b права. Обчислюють його «визначником» i j k; a₁ a₂ a₃; b₁ b₂ b₃. Властивості: b × a = −(a × b); a × b = 0 ⇔ a ∥ b; добуток лінійний за кожним аргументом. Корисні таблиця i × j = k, j × k = i, k × i = j і тотожність Лагранжа |a × b|² = |a|²|b|² − (a·b)².

Мішаний добуток (a, b, c) = (a × b)·c дорівнює визначнику матриці з рядків a, b, c. |(a, b, c)| — об'єм паралелепіпеда на a, b, c. Об'єм тетраедра ABCD = ⅙·|(B − A, C − A, D − A)|. Циклічна перестановка не змінює (a, b, c), а обмін двох векторів змінює знак. (a, b, c) = 0 ⇔ вектори компланарні.

Площа трикутника в просторі: S = ½·|(B − A) × (C − A)|. Наприклад, для A(3, 1, 5), B(4, 7, 6), C(2, 1, 1) маємо (1, 6, 1) × (−1, 0, −4) = (−24, 3, 6), тож S = ½√621 = 3√69/2.

Алгебраїчні структури

  • Група — множина з асоціативною операцією, нейтральним елементом і оберненими: (ℤ, +), Sₙ, GL(n, ℝ) за множенням, (ℤₙ, +). Кільце має ще й множення з дистрибутивністю: ℤ, ℝ[x], Mat(n, ℝ) (некомутативне). Поле — комутативне кільце, де кожен ненульовий елемент обертовний: ℚ, ℝ, ℂ, ℤₚ для простого p.
  • Поле ℤₚ: арифметика за модулем p. Системи над ℤₚ розв'язуються тим самим Гаусом, але ділення замінюється множенням на обернений за модулем. Наприклад, у ℤ₅ маємо 2⁻¹ = 3, бо 2·3 = 6 ≡ 1.
  • Гомоморфізм f(ab) = f(a)f(b) зберігає операцію: det: GL(n, ℝ) → ℝ*, бо det(AB) = det A·det B; exp: (ℝ, +) → (ℝ₊*, ·); z ↦ |z|. Ізоморфізм — це бієктивний гомоморфізм. Матриці підстановок Pσ (одиниця на місці (σ(j), j)) утворюють групу, ізоморфну Sₙ: PσPτ = Pστ. Група симетрій правильного трикутника D₃ ізоморфна S₃.
  • Елементарні матриці й LU. Кожне елементарне перетворення рядків є множенням зліва на елементарну матрицю, тому Жордан–Гаус для A⁻¹ — це добуток таких матриць. Якщо прямий хід обходиться без обміну рядків, то A = LU: L — нижньотрикутна з одиницями на діагоналі, U — ступінчаста. Тоді Ax = b розв'язують у два кроки: Ly = b, потім Ux = y.

Блок 6. Поглиблено: лінійні простори

Режим «Поглиблений». Блоки 6–8 повторюють структуру другої частини курсу (розділи 2–4): лінійні простори, евклідові простори, лінійні перетворення. Вони пояснюють, чому працюють методи з блоків 1–4, і готують до наступних курсів: статистики, оптимізації, машинного навчання. Для тестів «Linear algebra basics» вони не обов'язкові.

Лінійний простір і підпростір

Лінійний простір V над полем F — це абелева група (V, +) з множенням на скаляри, для якого λ(μa) = (λμ)a, λ(a + b) = λa + λb, (λ + μ)a = λa + μa і 1·a = a. Приклади: Fⁿ, многочлени F[t] і Fₙ[t] (степінь ≤ n), матриці Mat(m×n, F), функції ℝ → ℝ. З аксіом випливає, що 0·a = 0, λ·0 = 0 і (−1)a = −a.

Підпростір W ⊂ V замкнений щодо додавання й множення на скаляр. Найшвидша перевірка на «ні»: чи лежить у W нуль. Приклади «так»: розв'язки однорідної системи, лінійна оболонка Lin(a₁, …, aₖ), многочлени з коренем α, симетричні матриці. Приклади «ні»: {x₁ + … + xₙ = 1} (немає нуля), цілочислові вектори (не замкнені щодо множення на ½), перша чверть (не замкнена щодо множення на −1).

Лінійна незалежність, базис, розмірність

Вектори a₁, …, aₖ лінійно незалежні, якщо α₁a₁ + … + αₖaₖ = 0 лише при всіх αᵢ = 0. Рівносильно: жоден вектор не виражається через попередні. Базис — це незалежна й повна система: кожен вектор розкладається за нею, причому однозначно. Коефіцієнти розкладу називають координатами. Усі базиси мають однакову кількість векторів (наслідок «леми про прополку»: незалежних не більше, ніж векторів у повній системі). Ця кількість — розмірність: dim Fⁿ = n, dim Fₙ[t] = n + 1, dim Mat(n, F) = n², а простір симетричних n×n має dim = n(n + 1)/2.

Будь-яку незалежну систему можна доповнити до базису. Простори однієї розмірності над одним полем ізоморфні, бо координати дають ізоморфізм V → Fⁿ. Тому многочлен a₀ + a₁t + a₂t² «є» вектором (a₀, a₁, a₂), а задачі про многочлени й матриці зводяться до систем у Fⁿ.

Матриця переходу між базисами

Нехай e і f — два базиси. Матриця переходу Te→f має в стовпцях координати нових векторів fⱼ у старому базисі e. Координати вектора пов'язані формулою xe = T·xf: щоб отримати старі координати, множимо T на нові. Звідси xf = T⁻¹xe, а Tf→e = Te→f⁻¹.

У ℝⁿ: якщо стовпці A — базис a, а стовпці B — базис b (обидва записані в стандартному базисі), то Ta→b = A⁻¹B. Обчислюють її одним Жорданом–Гаусом: [A | B] → [I | A⁻¹B].

Ранг матриці

Теорема про ранг матриці: рядковий ранг = стовпцевий ранг = найбільший порядок ненульового мінора. Практично ранг дорівнює кількості ненульових рядків після зведення до ступінчастого вигляду. Метод облямовуючих мінорів: знайшли ненульовий мінор порядку k, тоді перебираємо лише ті мінори порядку k + 1, що його містять. Якщо всі вони нульові, rank = k.

Стовпці з ведучими елементами початкової матриці утворюють базис простору стовпців: елементарні перетворення рядків не змінюють лінійних залежностей між стовпцями. Тому dim Lin(a₁, …, aₖ) = rank(a₁, …, aₖ). Корисні нерівності: rank(AB) ≤ min(rank A, rank B), rank(A + B) ≤ rank A + rank B.

Чотири основні простори й теорія СЛАР

Для A розміру m×n з рангом r: простір рядків R(A) ⊂ Fⁿ і простір стовпців C(A) ⊂ Fᵐ мають розмірність r; нуль-простір N(A) = {x : Ax = 0} має розмірність n − r; лівий нуль-простір N(Aᵀ) має розмірність m − r. Звідси теорема про ранг: dim N(A) + rank A = n, тобто «вільні змінні + ведучі = невідомі».

Кронекер–Капеллі. Ax = b сумісна ⇔ rank A = rank [A | b], тобто ⇔ b ∈ C(A). Сумісна система визначена ⇔ r = n.
Структура розв'язків. Усі розв'язки: x = c₀ + N(A), де c₀ — один частковий розв'язок. Базис N(A) називають фундаментальною системою розв'язків (n − r векторів). Множину c₀ + U називають лінійним многовидом: це «зсунутий» підпростір.

Навпаки, будь-який підпростір розмірності d в Fⁿ є множиною розв'язків однорідної системи рангу n − d. Рівняння для Lin(a₁, …, aₖ) отримують так: шукаємо всі y з yᵀaᵢ = 0, а кожен знайдений y дає рівняння yᵀx = 0.

Сума, перетин, пряма сума

Сума V + W = {v + w} і перетин V ∩ W знову є підпросторами. Формула Грассмана: dim(V + W) + dim(V ∩ W) = dim V + dim W. Базис суми: зведіть матрицю з усіх векторів обох систем. Перетин: знайдіть усі розв'язки α₁a₁ + … + αₖaₖ = β₁b₁ + … + βₗbₗ, тобто нуль-простір матриці [a | b]. Сума пряма (V ⊕ W), якщо V ∩ W = {0}; тоді кожен x однозначно розкладається як x = v + w («проєкції x на V уздовж W і на W уздовж V»).

Приклад: Mat(n, ℝ) = {симетричні} ⊕ {кососиметричні}, бо A = (A + Aᵀ)/2 + (A − Aᵀ)/2. Для сум зручніше задавати підпростори базисами, для перетинів — системами рівнянь.

Простори над скінченними полями

Над ℤ₂ (і будь-яким ℤₚ) уся теорія працює так само: Гаус, ранг, базис, розмірність. Але тепер просторів, базисів і розв'язків скінченна кількість. Над полем з q елементами |Fⁿ| = qⁿ, однорідна система рангу r має qn−r розв'язків, а впорядкованих базисів Fⁿ є (qⁿ − 1)(qⁿ − q)…(qⁿ − qⁿ⁻¹). Над ℤ₂ додавання — це XOR, і на цьому побудовано коди Геммінга: перевірна матриця H, нуль-простір N(H) складається з кодових слів, а синдром Hy вказує позицію помилки.

Чому працюють методи: доведення

  • Гаусс не змінює розв'язків. Кожне елементарне перетворення рядків — це множення зліва на оборотну елементарну матрицю E. З Ax = b випливає EAx = Eb, і навпаки (множимо на E⁻¹).
  • [A | I] → [I | A⁻¹]. Якщо E_k…E₁A = I, то добуток E_k…E₁ = A⁻¹. Ті самі перетворення, застосовані до I, дають саме цей добуток.
  • det(AB) = det A·det B. Для елементарних матриць це перевіряється напряму (властивості det для рядків). Оборотна A — добуток елементарних, тож рівність переноситься; для виродженої A обидві частини дорівнюють 0.
  • Крамер. Із A⁻¹ = adj A / det A маємо x = A⁻¹b = adj A·b / det A, а j-та координата adj A·b — це розклад Δⱼ за j-м стовпцем. Якщо Δ = Δ₁ = … = Δₙ = 0, Крамер нічого не каже: система може мати і безліч розв'язків, і жодного.

Блок 7. Поглиблено: евклідові простори

Скалярний добуток, норма, нерівність Коші–Буняковського

Скалярний добуток на дійсному просторі — функція ⟨x, y⟩, яка (1) додатно визначена: ⟨x, x⟩ > 0 при x ≠ 0, (2) симетрична і (3) лінійна за кожним аргументом. Простір зі скалярним добутком називають евклідовим. Приклади: стандартний ⟨x, y⟩ = xᵀy, «зважений» 3x₁y₁ + 2x₂y₂, інтегральний ⟨f, g⟩ = ∫ₐᵇ f g dx. Не є скалярними добутками |x₁y₁| + |x₂y₂| (не лінійний) і x₁y₁ + x₃y₃ у ℝ³ (⟨e₂, e₂⟩ = 0). У комплексному випадку симетрію замінює ⟨x, y⟩ = ⟨y, x⟩‾.

Матриця Грама G = (⟨aᵢ, aⱼ⟩). Якщо x, y задано координатами в базисі з матрицею Грама G, то ⟨x, y⟩ = xᵀGy, тож скалярний добуток досить знати на парах базисних векторів. Норма ‖x‖ = √⟨x, x⟩, відстань d(x, y) = ‖x − y‖, кут: cos φ = ⟨x, y⟩ / (‖x‖·‖y‖).

Коші–Буняковський–Шварц: |⟨u, v⟩| ≤ ‖u‖·‖v‖, рівність ⇔ u ∥ v. Звідси випливають коректність косинуса, нерівність трикутника ‖u + v‖ ≤ ‖u‖ + ‖v‖ і купа нерівностей: (x₁ + … + xₙ)² ≤ n(x₁² + … + xₙ²); (a + b + c + d)(1/a + 1/b + 1/c + 1/d) ≥ 16; max(x + 2y + 3z) при x² + y² + z² = 14 дорівнює 14.
Також корисні теорема Піфагора (u ⟂ v ⇔ ‖u + v‖² = ‖u‖² + ‖v‖²), тотожність паралелограма ‖u + v‖² + ‖u − v‖² = 2‖u‖² + 2‖v‖² і поляризація ⟨u, v⟩ = (‖u + v‖² − ‖u − v‖²)/4.

Ортогональність і процес Грама–Шмідта

Попарно ортогональні ненульові вектори завжди лінійно незалежні. В ортонормованому базисі (⟨eᵢ, eⱼ⟩ = 0 при i ≠ j, ‖eᵢ‖ = 1) координати знаходять без жодної системи: xⱼ = ⟨x, eⱼ⟩. Проєкція u на напрям v: (⟨u, v⟩/‖v‖²)·v, а залишок u − proj ⟂ v.

Грам–Шмідт: u₁ = a₁; uₖ = aₖ − Σj<k (⟨aₖ, uⱼ⟩/‖uⱼ‖²)·uⱼ, тобто від кожного наступного вектора віднімаємо його проєкції на вже знайдені. Якщо якийсь uₖ = 0, то aₖ виражається через попередні. Наприкінці нормуємо. Ортогоналізація 1, t, t², t³ з ⟨f, g⟩ = ∫₋₁¹ fg dt дає многочлени Лежандра 1, t, t² − ⅓, t³ − ³⁄₅t. Ортогональна матриця QᵀQ = I має ортонормовані стовпці, зберігає довжини й кути, Q⁻¹ = Qᵀ, det Q = ±1. Ортогональні 2×2 — це рівно повороти (det = 1) і симетрії (det = −1).

Ортогональне доповнення й проєкція на підпростір

U⟂ = {v : ⟨u, v⟩ = 0 для всіх u ∈ U} — підпростір, і E = U ⊕ U⟂. Тому кожен x однозначно розкладається як x = p + h, де p ∈ U — ортогональна проєкція, а h ∈ U⟂ — ортогональна складова. Якщо U = Lin(a₁, …, aₖ) зі стовпцями-матрицею A, то U⟂ = N(Aᵀ): шукаємо всі y з aᵢ·y = 0. Проєкцію знаходять з нормальних рівнянь AᵀAc = Aᵀx, p = Ac (якщо aᵢ залежні, спершу виберіть базис).

Ортогональність основних просторів дійсної матриці: R(A)⟂ = N(A) у ℝⁿ і C(A)⟂ = N(Aᵀ) у ℝᵐ. Отже ℝⁿ = R(A) ⊕ N(A) і ℝᵐ = C(A) ⊕ N(Aᵀ). Це «велика картинка» Стренга: Ax = 0 означає, що x ортогональний кожному рядку.

Відстані й кути між лінійними об'єктами

Відстань від точки x до многовиду P = x₀ + U дорівнює ‖h‖, де h — ортогональна складова x − x₀ щодо U. Відстань між многовидами x₁ + U₁ і x₂ + U₂ дорівнює нормі ортогональної складової x₁ − x₂ щодо U₁ + U₂. Кут між x і підпростором U — це кут між x та його проєкцією p (або 90°, якщо p = 0). Діагональ n-вимірного куба утворює з кожним ребром кут arccos(1/√n), і він прямує до 90° при n → ∞.

Метод найменших квадратів

Коли рівнянь більше, ніж невідомих, і система несумісна (наприклад, пряма через багато точок вимірювань), шукають x, що мінімізує ‖Ax − b‖². Такий x задовольняє нормальні рівняння AᵀAx = Aᵀb: Ax — проєкція b на C(A), а залишок b − Ax ⟂ C(A). Це основа лінійної регресії в статистиці та ML.

Пряма y = a + bx через (0, 1), (1, 3), (2, 4), (3, 4): AᵀA = 4 6; 6 14, Aᵀb = (12, 23), звідки a = 3/2, b = 1: y = 1,5 + x.
Чекпоінти блоку 7

1) Як знайти координати x в ортонормованому базисі? xⱼ = ⟨x, eⱼ⟩, без розв'язання системи.
2) dim U = 2 у ℝ⁵. Чому дорівнює dim U⟂? 3, бо ℝ⁵ = U ⊕ U⟂.
3) Що дає Грам–Шмідт для залежної системи? Нульовий вектор на тому кроці, де aₖ виражається через попередні.

Блок 8. Поглиблено: лінійні перетворення

Лінійний оператор і його матриця

Відображення φ: V → V лінійне, якщо φ(x + y) = φ(x) + φ(y) і φ(αx) = αφ(x). Швидкі тести на «ні»: φ(0) ≠ 0 (зсув, наприклад x₂ + 1) або нелінійні вирази (x₃², x₁x₂). Матриця оператора Φₑ в базисі e має в j-му стовпці координати φ(eⱼ). Тоді φ(x) = Φₑx у координатах, а сумі, множенню на скаляр і композиції операторів відповідають Φ + Ψ, αΦ і ΦΨ.

Важливі матриці: поворот Pα = cos α -sin α; sin α cos α; симетрія відносно прямої під кутом α до Ox Σα = cos 2α sin 2α; sin 2α -cos 2α; проєкція на напрям a: aaᵀ/(aᵀa); симетрія відносно площини з одиничною нормаллю n: I − 2nnᵀ. Композиція двох симетрій ΣαΣβ є поворотом на 2(α − β).

Зміна матриці при заміні базису, подібність

Якщо T = Te→f, то Φf = T⁻¹Φₑ T. Матриці A і B = T⁻¹AT називають подібними: це один оператор, записаний у різних «системах координат». Подібність — відношення еквівалентності. У подібних матриць однакові det, слід tr (бо tr(AB) = tr(BA)), характеристичний многочлен і власні значення.

Приклад: симетрія відносно y = x у базисі (1, 1), (1, −1) має матрицю 1 0; 0 -1. Перший вектор лежить на осі симетрії і не змінюється, другий перпендикулярний і перевертається.

Ядро й образ оператора

Ker φ = {x : φ(x) = 0} = N(Φ), Im φ = {φ(x)} = C(Φ). Обидва є підпросторами, і dim Ker φ + dim Im φ = dim V. Оператор оборотний ⇔ Ker φ = {0} ⇔ Im φ = V ⇔ det Φ ≠ 0. Проєкція має ядро «вздовж чого проєктуємо» і образ «на що проєктуємо»; поворот має нульове ядро.

Власні значення і власні вектори

Ненульовий вектор v — власний, якщо Av = λv: перетворення лише розтягує його вздовж власного напряму. Число λ — власне значення. З (A − λI)v = 0 і v ≠ 0 маємо det(A − λI) = 0 — характеристичне рівняння. Власний підпростір Vλ = N(A − λI) складається з власних векторів і нуля.

Для 2×2: λ² − (tr A)·λ + det A = 0. Звідси λ₁ + λ₂ = tr A, λ₁λ₂ = det A. Загалом сума власних значень дорівнює tr A, а добуток — det A.
Геометрія: поворот на кут, відмінний від 0° і 180°, не має дійсних власних значень (жоден напрям не зберігається); у просторі поворот навколо осі має λ = 1 вздовж осі. Симетрія має λ = 1 (вздовж осі) і λ = −1 (перпендикулярно); проєкція має λ = 1 і λ = 0.

Алгоритм: 1) розв'язати det(A − λI) = 0; 2) для кожного λ розв'язати однорідну систему (A − λI)v = 0 методом Гаусса; її ненульові розв'язки — власні вектори.

Діагоналізація і степені матриць

Власні вектори для різних λ лінійно незалежні, тож n різних власних значень гарантують діагоналізовність. Критерій: A діагоналізовна ⇔ сума алгебраїчних кратностей (кратностей коренів характеристичного многочлена) дорівнює n і для кожного λ геометрична кратність dim Vλ дорівнює алгебраїчній. Тоді A = PDP⁻¹: стовпці P — власні вектори, D — діагональна матриця власних значень, і Aⁿ = PDⁿP⁻¹.

Приклад: 2 1; 1 2 має λ = 1, 3 з векторами (1, −1), (1, 1), тож Aⁿ = ½·3ⁿ+1 3ⁿ−1; 3ⁿ−1 3ⁿ+1. Контрприклад: 1 1; 0 1 має λ = 1 кратності 2, але V₁ одновимірний, тому вона не діагоналізовна.

Симетричні матриці: зведення до головних осей

Спектральна теорема. Для дійсної симетричної S усі власні значення дійсні, власні вектори для різних λ ортогональні, і існує ортогональна Q з S = QΛQᵀ. Алгоритм: знайти λ; у кожному Vλ обрати ортонормований базис (Грам–Шмідт, якщо dim Vλ > 1); записати ці вектори в стовпці Q. Гамільтон–Келі: матриця задовольняє власне характеристичне рівняння; для 2×2 це A² − (tr A)A + (det A)I = O, звідки A⁻¹ = ((tr A)I − A)/det A.

Чекпоінти блоку 8

1) tr A = 7, det A = 12 для 2×2. Власні значення? λ² − 7λ + 12 = 0 ⇒ 3 і 4.
2) Чому поворот на 90° не має дійсних власних значень? λ² + 1 = 0; геометрично жоден напрям не лишається на місці.
3) λ = 0 має алгебраїчну кратність 2, але dim V₀ = 1. Чи діагоналізовна матриця? Ні: власних векторів не вистачає на базис.
