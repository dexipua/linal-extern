# Лінал · екстерн

Статичний сайт для підготовки до курсу «Linear algebra basics» (KSE): конспект, 121 задача з відповідями, тренажер із випадковими задачами, лабораторія (візуалізатор перетворень і пісочниця Гаусса), 3 пробні контрольні з таймером і шпаргалка А4.

Сторінки: `index.html`, `material.html`, `problems.html`, `trainer.html`, `lab.html`, `tests.html`, `cheatsheet.html`. Спільні стилі та скрипти лежать у `assets/`. Збирати нічого не треба: це чистий HTML/CSS/JS, який публікується через GitHub Pages.
